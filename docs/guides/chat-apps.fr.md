# Chat channels in this fork

Supported channels are Weixin, WeCom, Feishu, DingTalk, QQ, OneBot, Telegram, and MQTT. The previous WeCom app/webhook variants have been replaced by the unified AI Bot WebSocket channel.

Use the maintained [channel guide](chat-apps.md) or [中文说明](chat-apps.zh.md), and the current [configuration example](../../config/config.example.json). Channel-specific values belong under `channel_list.<name>.settings`.
